# Code de conduite

AgriInfo BF est un projet ouvert pour les agriculteurs et celles et ceux qui les aident.

## On attend

- Respect, même en désaccord
- Conseils utiles, sourcés si possible
- Messages adaptés à tous les âges

## On n’accepte pas

- Insultes, harcèlement, menaces
- Fausses informations agricoles présentées comme officielles
- Publicité cachée pour un produit
- Contenu inapproprié
